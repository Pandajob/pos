============================================================
 POS Cash Drawer / Print Agent — วิธีรันเมื่อย้ายไปเครื่องอื่น
============================================================

โปรแกรมตัวนี้คือ "ตัวแทนพิมพ์" ที่รันบนเครื่องที่ต่อกับเครื่องพิมพ์/ลิ้นชักเงิน
หน้าเว็บ POS จะคุยกับมันผ่าน http://127.0.0.1:9991 (เฉพาะในเครื่องเดียวกัน)

ตอนนี้ agent.js ถูกแก้ให้ "ไม่ต้องใช้ node_modules" แล้ว
=> ขอแค่มี Node.js ในเครื่อง ก็ดับเบิลคลิก start.bat รันได้ทันที


------------------------------------------------------------
 วิธีที่ 1 (แนะนำ) — เครื่องมี Node.js
------------------------------------------------------------
1. ติดตั้ง Node.js รุ่น LTS จาก https://nodejs.org (ติดตั้งครั้งเดียว)
2. ดับเบิลคลิก  start.bat
   - start.bat จะหา Node ให้เอง (ทั้งใน PATH และตำแหน่งติดตั้งทั่วไป)
   - ถ้าไม่เจอ Node และเครื่องมี winget จะถามว่าจะติดตั้งให้อัตโนมัติไหม
3. หน้าต่างจะโชว์ Token + พอร์ต
4. เปิดหน้า POS > ตั้งค่า แล้วกดปุ่ม "ตั้งค่าอัตโนมัติ" (จับคู่ token ให้เอง)
   จากนั้นเลือกเครื่องพิมพ์ แล้วกดบันทึก


------------------------------------------------------------
 วิธีที่ 2 — เครื่องไม่มี Node.js (ใช้ตัว Portable)
------------------------------------------------------------
ในโฟลเดอร์ dist มีโปรแกรมแบบ Portable ที่รวม Node ไว้แล้ว (ไม่ต้องติดตั้งอะไร):
   dist\win-unpacked\POS Cash Drawer.exe
ดับเบิลคลิกไฟล์นี้ได้เลย
(ถ้าดับเบิลคลิก start.bat แล้วไม่เจอ Node มันจะเปิด exe ตัวนี้ให้อัตโนมัติด้วย)


------------------------------------------------------------
 วิธีที่ 3 — วาง Node แบบพกพาไว้ในโฟลเดอร์ (ไม่อยากติดตั้ง)
------------------------------------------------------------
1. ดาวน์โหลด Node.js "Windows Binary (.zip)" จาก nodejs.org
2. แตกไฟล์ แล้วก๊อป node.exe มาไว้ที่:
      local-agent\node\node.exe
3. ดับเบิลคลิก start.bat — มันจะใช้ node.exe ตัวนี้ก่อนเป็นอันดับแรก
   (ก๊อปทั้งโฟลเดอร์ POS ไปเครื่องไหนก็รันได้ โดยไม่ต้องลง Node)


------------------------------------------------------------
 หมายเหตุ / แก้ปัญหา
------------------------------------------------------------
- ต้องเปิด start.bat ทิ้งไว้ตลอดเวลาที่ใช้งานพิมพ์ (ปิดหน้าต่าง = หยุดทำงาน)
- ถ้าขึ้นว่าพอร์ต 9991 ถูกใช้งานแล้ว = มี agent ตัวเก่ารันอยู่ ให้ปิดก่อน
  หรือแก้ค่า "port" ในไฟล์ config.json
- ตั้งให้เปิดเองตอนเปิดเครื่อง: กด Win+R พิมพ์ shell:startup
  แล้วสร้าง shortcut ของ start.bat วางไว้ในโฟลเดอร์นั้น
- config.json เก็บ token + เครื่องพิมพ์ที่เลือกไว้ (ก๊อปไปด้วยได้
  หรือจะปล่อยให้สร้างใหม่อัตโนมัติตอนรันครั้งแรกก็ได้)
- ไฟล์ install.bat ใช้เฉพาะตอนต้องการ serialport (เครื่องต่อ COM)
  หรือจะ build โปรแกรมเดสก์ท็อปเท่านั้น — การพิมพ์ปกติไม่ต้องใช้
