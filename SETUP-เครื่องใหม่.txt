============================================================
 ติดตั้ง POS บนเครื่องใหม่ (ย้าย/สำรองทั้งระบบ)
============================================================

** ตอบสั้น ๆ: ก๊อปโฟลเดอร์อย่างเดียว "ยังไม่พอ" **
ตัวเว็บ POS ต้องมี XAMPP + ฐานข้อมูล ส่วนตัว Agent พิมพ์ ก๊อปวางรันได้เลย
ทำตาม 5 ขั้นนี้แล้วใช้งานได้ครบ:

------------------------------------------------------------
 1) ติดตั้ง XAMPP
------------------------------------------------------------
- โหลด XAMPP (PHP 8.2) จาก https://www.apachefriends.org
- เปิด XAMPP Control Panel แล้ว Start ทั้ง Apache และ MySQL
- ต้องเปิด extension "intl" ใน php.ini (ปกติเปิดอยู่แล้ว)

------------------------------------------------------------
 2) วางโฟลเดอร์โปรเจค
------------------------------------------------------------
- ก๊อปโฟลเดอร์ POS ทั้งหมดไปไว้ที่:   C:\xampp\htdocs\POS
  (สำคัญ: ต้องวางที่ path นี้ เพราะตั้งค่า URL ไว้เป็น /pos/public/)
  ถ้าต้องวางที่อื่น ให้แก้ 2 จุด:
     - .env บรรทัด  app.baseURL
     - public/.htaccess บรรทัด  RewriteBase

------------------------------------------------------------
 3) สร้าง/อัปเดตฐานข้อมูล (สำคัญที่สุด — DB ไม่ได้อยู่ในโฟลเดอร์)
------------------------------------------------------------
*** มี 2 ไฟล์ เลือกใช้ให้ถูก ไม่งั้นข้อมูลหาย ***

  [A] pos_db.sql         = เครื่องใหม่/ติดตั้งครั้งแรก (ยังไม่มีข้อมูล)
      -> มีคำสั่ง DROP TABLE + ข้อมูลตัวอย่าง
      -> ถ้า import ทับเครื่องที่มีข้อมูลอยู่แล้ว >> ข้อมูลเก่าหายหมด! <<

  [B] pos_db_update.sql  = เครื่องที่มีข้อมูลขายอยู่แล้ว อยากอัปเดตโครงสร้าง
      -> ไม่มี DROP, ไม่มีข้อมูล, ใช้ CREATE TABLE IF NOT EXISTS
      -> เพิ่มเฉพาะ "ตารางที่ยังไม่มี" ข้อมูลเดิมอยู่ครบ ปลอดภัย

วิธี import (phpMyAdmin):
- เปิด http://localhost/phpmyadmin > เมนู "นำเข้า" (Import) > เลือกไฟล์ > Go

วิธี import (command line):
   เครื่องใหม่:        C:\xampp\mysql\bin\mysql.exe -u root < pos_db.sql
   อัปเดตเครื่องเก่า:  C:\xampp\mysql\bin\mysql.exe -u root < pos_db_update.sql

** ข้อจำกัดของ [B]: เพิ่มได้เฉพาะ "ตารางใหม่" — ถ้าเวอร์ชันใหม่มีการ
   "เพิ่มคอลัมน์" ในตารางเดิม ไฟล์นี้จะข้ามให้ (เพราะตารางมีอยู่แล้ว)
   กรณีนั้นต้องใช้คำสั่ง ALTER TABLE แยก แจ้งผมได้ว่าอัปจากเวอร์ชันไหน **

------------------------------------------------------------
 4) ตรวจไฟล์ .env
------------------------------------------------------------
- เปิดไฟล์ .env เช็คว่า database.default.username / password
  ตรงกับ MySQL ของเครื่องใหม่ (ค่าเริ่ม XAMPP คือ user=root, password ว่าง)

------------------------------------------------------------
 5) เปิดใช้งาน
------------------------------------------------------------
- เปิดเว็บ:  http://localhost/pos/public/
- ล็อกอินด้วยบัญชีแอดมินเดิม (มากับฐานข้อมูลที่ import)

------------------------------------------------------------
 ตัว Agent พิมพ์ใบเสร็จ / เปิดลิ้นชัก
------------------------------------------------------------
- อยู่ในโฟลเดอร์ local-agent — ก๊อปไปวางรันได้ทุกเครื่อง
- รายละเอียดดูไฟล์  local-agent\HOW-TO-RUN.txt
- สรุป: มี Node.js -> ดับเบิลคลิก local-agent\start.bat
        ไม่มี Node -> ใช้ตัว portable ใน local-agent\dist\

------------------------------------------------------------
 หมายเหตุสำคัญ
------------------------------------------------------------
- ไฟล์ pos_db.sql ในโฟลเดอร์นี้คือ "สำเนาฐานข้อมูล ณ วันที่ส่งออก"
  ถ้าต้องการย้ายข้อมูลล่าสุด ให้ export ใหม่ก่อนก๊อปทุกครั้ง:
     C:\xampp\mysql\bin\mysqldump.exe -u root --databases pos_db ^
       --add-drop-table --default-character-set=utf8mb4 ^
       --result-file=C:\xampp\htdocs\POS\pos_db.sql
- ข้อมูลการขาย/สต๊อก ทั้งหมดอยู่ในฐานข้อมูล MySQL ไม่ใช่ในไฟล์โค้ด
